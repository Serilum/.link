## Permanent links for Serilum's mod collection.

The links are defined in the [_redirects](_redirects) file, which is served at **[link.serilum.com](https://link.serilum.com/)**. For example:\
https://link.serilum.com/curseforge -> https://curseforge.com/members/serilum/projects

Any link that doesn't exist goes to https://serilum.com.

Redirect analytics are anonymous, see the [privacy policy](https://serilum.com/privacy-policy) for more information.
